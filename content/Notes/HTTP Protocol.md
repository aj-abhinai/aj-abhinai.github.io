- Hyper Text Transfer Protocol
- Fundamental communication protocol used for transferring data between a web browser (client) and web server 

###### HTTP Methods

| Method | Purpose       |
| ------ | ------------- |
| GET    | retrieve data |
| POST   | send data     |
| PUT    | update data   |
| DELETE | remove data   |

- 2XX - Success codes 
- 3XX - Redirection codes
- 4xx - Client Error Codes 
- 5xx - Server Error codes
